# Completionist Log

A phone app for tracking Final Fantasy XIV completion, expansion by expansion: story, duties, jobs, collections, exchanges, world content, leves, Gold Saucer, PvP and more.

- Install: open https://kevinjdexter.github.io/completionist-log/ in Chrome on Android, then **Add to Home screen** / **Install app**.
- Works offline once opened. Progress is saved on the device; use **Settings → Export backup** now and then.
- Game data: patch 7.57, from the game's data files (xivapi/ffxiv-datamining) and Teamcraft.
